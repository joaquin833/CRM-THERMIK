# Manual del ejecutivo comercial

1. Registra el contacto o empresa una sola vez.
2. Crea el proyecto y la oportunidad relacionados.
3. Crea la cotización con N.º obligatorio y único.
4. Agrega ítems y verifica neto, IVA y total.
5. Al enviar, registra próxima acción y fecha de seguimiento.
6. Usa **Agenda** para completar tareas y sincronizarlas con Calendar.
7. Usa **Centro de IA** solo como apoyo y revisa cada borrador antes de enviarlo.
8. Busca siempre por `Cotización N.º` para acceder al historial correcto.
